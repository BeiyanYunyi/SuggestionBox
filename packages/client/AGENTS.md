# SuggestionBox Client

This folder includes the client-side code for the SuggestionBox application. The application will be built into:

- a Vue component (dist/App.vue)
- a Web Component (dist/aio.js)

## Tech Stack

- UnoCSS
- ESLint Antfu Config
- Vue 3

## Commands

- `pnpm dev`: Start the development server
- `pnpm build`: Build the production bundle
- `pnpm lint`: Run ESLint
