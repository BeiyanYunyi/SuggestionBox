# Suggestion Box

This is a monorepo for the Suggestion Box project.

## Project Structure

The monorepo includes:

- client frontend code in `packages/client`
- server code and admin frontend code in `packages/worker`
  - admin frontend code in `packages/worker/src/admin`
  - server code (for both client and admin) in `packages/worker/src/server`

Visit the directories before for specific information.
